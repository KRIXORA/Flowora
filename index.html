How to use Flowora

1

Add today’s tasks

Type in Quick Add below and press Enter. Mark done with the checkbox. Filter with All / Active / Done.

2

Plan your day

Open Planner for Morning / Afternoon / Evening blocks. Drag priorities into the right time slot.

3

Build habits & goals

Use Habits for daily streaks and Goals for longer targets. Update progress as you go.

4

Use the Focus Timer

Start a Focus Session for 25-minute deep work. Take breaks, then come back to the dashboard.

5

Ask the AI coach

In AI Coach try: “Add task: Finish report”, “Morning brief”, or “Analyze workspace”.

6

Install & backup

Install the app from the browser menu (Add to Home Screen). In Settings, Export backup so your data stays safe.

Tip: Press Ctrl + K (or ⌘ + K) to open quick search anywhere.
